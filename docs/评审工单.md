## 你要评的东西

一个**本地优先、单人使用**的 AI 记忆引擎，目标是把"跨会话记忆"做成可审计、可回滚、可视化的四层结构，并通过 MCP 接入 DSH / Claude Code / opencode / ZCode / WorkBuddy 等宿主，支持同一用户的多 Agent 交叉验证（一个写、一个审）。

**硬约束（评审时请别建议违反它们）**
1. 单人本地，Windows 优先，无运维、无 CI。
2. 未配置任何模型 API 时必须可用（零 LLM 可运行）。
3. 只用 MCP 作为宿主边界，不绑定任何单一宿主。
4. 存储用 SQLite 单文件，不引图数据库 / 向量服务。
